# 검증 세트·교차 검증·그리드 서치 질문 정리

> [[ch05|← 5장 원리 노트로 돌아가기]]

## score만 했는데 왜 테스트 세트에 맞춰지나

`score()`는 모델을 바꾸지 않는다. 바뀌는 건 **사람의 선택**.

```
max_depth=1 → test 0.80
max_depth=2 → test 0.82
max_depth=3 → test 0.84   ← "이게 제일 좋네" 선택
```

모의고사 점수가 가장 높은 공부법을 고른 뒤 "내 실력 = 모의고사 점수"라고 하는 것과 같다.
시도가 많을수록 우연히 그 시험지와 잘 맞은 설정이 뽑힌다 → 테스트 점수가 부풀려짐.
→ 설정 고르기는 **검증 세트(교차 검증)**, 테스트는 마지막 한 번.

## cross_validate 문법

```python
scores = cross_validate(dt, train_input, train_target, cv=5)
#                       모델  훈련 특성   훈련 정답     분할 방법
```

- 반환값은 **딕셔너리** → `scores['test_score']`처럼 키로 꺼냄
- `'test_score'` = 검증 폴드 점수 (이름만 test)
- 모델을 **복사**해서 학습 → 원본 `dt`는 그대로

## cv= 에 숫자도 객체도 들어가는 이유

| `cv=` | 의미 |
|---|---|
| 생략 / `5` | 기본 분할기(분류: `StratifiedKFold`, 회귀: `KFold`)에 조각 수만 전달 |
| 분할기 객체 | 조각 수 + 섞기 + random_state를 직접 지정 |

숫자로는 섞기를 못 켬 → 섞으려면 `StratifiedKFold(n_splits=10, shuffle=True, random_state=42)`.
분할기는 설정을 기억해야 하므로 클래스 → 객체를 만들어 넘긴다.

## cv는 하이퍼파라미터인가?

아님. **평가 방법**이다. cv를 바꿔도 트리 자체는 안 바뀐다.

```
하이퍼파라미터 → DecisionTreeClassifier(...) 안에 : 트리를 어떻게 만들지
cv             → cross_validate / GridSearchCV 에  : 만든 트리를 어떻게 채점할지
```

| 트리 하이퍼파라미터 | 의미 |
|---|---|
| `max_depth` | 최대 깊이 |
| `min_impurity_decrease` | 정보 이득이 이 값 미만이면 안 나눔 |
| `min_samples_split` | 노드 샘플이 이 수 이상이어야 나눌 수 있음 |
| `min_samples_leaf` | 리프에 최소 이만큼 남아야 함 |
| `max_leaf_nodes` | 리프 최대 개수 |
| `criterion` | `'gini'` / `'entropy'` |

## params 딕셔너리

```python
params = {'min_impurity_decrease': [0.0001, 0.0002, 0.0003, 0.0004, 0.0005]}
#          키: 모델 매개변수 이름(글자까지 정확히)   값: 후보 리스트
```

키를 여러 개 넣으면 **모든 조합**(격자의 모든 칸)을 시험 → 그리드 서치.
책이 처음에 하나만 바꾼 건 사용법을 보여주려는 순서일 뿐, 실제로는 여러 개를 동시에 탐색하는 게 맞다.

## refit — "전체 훈련 세트로 다시 훈련"

교차 검증 중 만든 모델들은 모두 훈련 세트의 **4/5만** 본 모델(점수 매기기용).

```
① 교차 검증으로 후보 채점 → best_params_ 선택       (설정 고르기)
② 그 설정으로 5197개 전부 다시 fit → best_estimator_   (진짜 모델 만들기, gs.fit 안에서 자동)
```

## dt = gs.best_estimator_ 를 빼먹으면

```python
dt.fit(sub_input, sub_target)     # 예전 dt (4157개, 기본 설정)
gs.fit(train_input, train_target) # gs 안에서 복사본으로 학습 → dt는 그대로
dt.score(...)                     # ❌ 예전 dt를 채점
dt = gs.best_estimator_           # ✅ 꺼내서 받아야 함 (또는 gs.score(...))
```
