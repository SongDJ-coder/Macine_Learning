# 손실은 틀린 "크기"만 보나? — 방향은 기울기가 담당

> [[ch04|← 4장 원리 노트로 돌아가기]]

**Q: 손실 함수는 음/양에 관계없이 오차가 큰지 아닌지만 보는 건가?**

## 1. 손실 값 = 크기만 (항상 0 이상)

```
정답    예측 p(양성)   손실
 1        0.9        −log(0.9)   = 0.11   거의 맞음
 1        0.1        −log(0.1)   = 2.30   너무 낮음
 0        0.1        −log(0.9)   = 0.11   거의 맞음
 0        0.9        −log(0.1)   = 2.30   너무 높음
```

"너무 낮음"과 "너무 높음"이 똑같이 +2.30. 3장에서 오차를 **제곱**한 것과 같은 이유 —
부호가 남으면 +오차와 −오차가 상쇄돼 전체가 0처럼 보일 수 있다.

## 2. 방향 = 기울기

```
손실
 │╲                    ╱
 │ ╲     기울기 −     ╱  기울기 +
 │  ╲   → w 키우기   ╱  → w 줄이기
 │   ╲_____●________╱
 └────────────────────── w
```

04-1의 **오차 × 특성값** = (p − 정답) × x 가 이 기울기다. p − 정답은 부호가 있다.

| | 부호 | 역할 |
|---|---|---|
| 손실 값 | 항상 ≥ 0 | 얼마나 틀렸나 (산의 높이) |
| 기울기 | + / − | 어느 쪽으로 고칠지 (내리막 방향) |
