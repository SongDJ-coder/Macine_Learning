# 로지스틱 회귀는 가중치를 어떻게 고치나

> [[ch04|← 4장 원리 노트로 돌아가기]]

**Q: 학습 = 가중치를 정하는 과정인 건 알겠는데, 어떤 식으로 고치나?
특성마다 따로 고치나? 값이 작은 특성은 불리하지 않나?**

## 1. 특성 1개, 생선 4마리로 단계별 계산

```
생선      :   A      B      C      D
길이 x    :  -2     -1     +1     +2      (표준화된 값)
정답 y    : 빙어(1) 빙어(1) 도미(0) 도미(0)
```

```
z = w·x + b  →  p = 시그모이드(z)  →  오차 = p − 정답  →  w ← w − 평균(오차 × x)
```

**반복 1회 (w = 0, b = 0에서 출발)**

```
p      :  0.5    0.5    0.5    0.5      ← 아무것도 모름
오차   : -0.5   -0.5   +0.5   +0.5
오차×x : +1.0   +0.5   +0.5   +1.0      → 평균 0.75
새 w   = 0 − 0.75 = −0.75               ← "길이가 작을수록 빙어"를 배움
```

**반복 결과**

```
반복   w       A의 p   B의 p   C의 p   D의 p    벌점
 0    0.00    0.50    0.50    0.50    0.50    0.693
 1   -0.75    0.82    0.68    0.32    0.18    0.294
 2   -1.09    0.90    0.75    0.25    0.10    0.198
 5   -1.63    0.96    0.84    0.16    0.04    0.108
```

오차가 줄수록 수정량도 줄어든다 (0.75 → 0.34 → 0.23 …).

## 2. 왜 빼나 (w가 음수가 되는 이유)

`평균(오차 × x)`는 **"w를 올리면 벌점이 늘어나는 정도"(기울기)** 다. 벌점을 줄이려면 반대로 가야 하므로 뺀다.
이것이 **경사 하강법**의 "하강" (04-2에서 본격적으로 다룸).

```
                    A(빙어)  B(빙어)  C(도미)  D(도미)
w = +0.75 (더하기)   0.18     0.32     0.68     0.82     ❌ 전부 반대로
w = −0.75 (빼기)     0.82     0.68     0.32     0.18     ✅ 전부 정답 쪽
```

생선 A 하나로 보면: x = −2, 빙어라서 확률(z)을 올려야 함 → `z = w × (−2)`이므로 **w를 내려야** z가 커짐.
이때 `오차 × x = (−0.5)(−2) = +1.0` (양수) → 빼면 w가 내려간다.

## 3. 특성이 여러 개면 — 계산은 따로, 연결은 "공통 오차"

```
w₁ 수정량 = 평균( 오차 × x₁ )
w₂ 수정량 = 평균( 오차 × x₂ )      ← 모두 "같은 오차"를 씀
w₃ 수정량 = 평균( 오차 × x₃ )
오차는 z = w₁x₁ + w₂x₂ + w₃x₃ + b 전체에서 나옴
```

**특성 3개 예시**

```
생선   정답      길이  높이  색
 A    빙어(1)    -2    -1   +1
 B    빙어(1)    +1    -2   -1     ← 길이는 긴데 빙어
 C    도미(0)    +1    +2   +1
 D    도미(0)     0    +1   -1
```

반복 1회 (오차 = [−0.5, −0.5, +0.5, +0.5]):

```
w₁(길이): +1.0 −0.5 +0.5 +0   → 평균 0.25  (B가 반대 신호 → 상쇄)
w₂(높이): +0.5 +1.0 +1.0 +0.5 → 평균 0.75  (4마리 모두 일관 → 크게 움직임)
w₃(색)  : −0.5 +0.5 +0.5 −0.5 → 평균 0     (완전 상쇄 → 안 움직임)
```

반복 2회: 오차가 생선마다 달라짐 → D(가장 많이 틀림, 색 −1)를 고치려고 **색 가중치가 처음 움직임**.

```
회차   w₁(길이)  w₂(높이)  w₃(색)    D의 p   벌점
  0     0.00      0.00     0.00     0.50   0.693
  1    -0.25     -0.75     0.00     0.32   0.263
  2    -0.34     -1.07     0.04     0.25   0.170
 10    -0.55     -1.99     0.26     0.09   0.047
 30    -0.66     -2.70     0.48     0.04   0.017
```

> [!tip] 핵심
> 한 특성이 해결한 부분은 오차에서 빠지므로, 다른 특성은 **남은 문제**에 반응한다.
> 실제 도미/빙어 데이터에서도 Height 가중치가 반복 5회에 −1.33까지 갔다가 최종 −1.01로 **다시 줄었다**
> (다른 특성이 따라오며 역할을 나눔). 목표는 각 가중치 최적화가 아니라 **전체 벌점 최소화**.

## 4. "값이 작은 특성은 불리하지 않나?"

1. **표준화**로 모든 특성을 평균 0, 표준편차 1로 맞춤 → 원래 크기(무게 720 vs 폭 6) 차이는 사라짐.
   표준화 후 "작다" = "평균보다 작다"(음수).
2. 가중치는 **부호까지 학습**한다. 실제 도미/빙어 가중치는 전부 음수:

```
              특성(표준화)                     × 가중치 → 기여도                 z      판정
생선0 도미 :  [ 0.92  0.61  0.81  1.85  1.00] → [-0.37 -0.35 -0.54 -1.88 -0.73]  -6.03  Bream
생선1 빙어 :  [-1.09 -1.69 -1.71 -1.70 -2.00] → [+0.44 +0.97 +1.13 +1.72 +1.47]  +3.57  Smelt
```

→ 작은 값 × 음수 가중치 = 양수 → **빙어** 쪽. "작다"가 오히려 빙어의 증거로 쓰인다.
