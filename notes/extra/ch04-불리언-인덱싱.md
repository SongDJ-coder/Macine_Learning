# 불리언 인덱싱 문법 — `|`, 괄호, 가운데 뚫린 문자

> [[ch04|← 4장 원리 노트로 돌아가기]]

**Q: `(train_target == 'Bream') | (train_target == 'Smelt')` 문법이 이해가 안 됨.
책의 or 문자는 가운데가 뚫려 있던데 맞는 코드인가?**

## 1. 가운데 뚫린 문자 = `|`

책 폰트에서 `|`(세로 막대)가 `¦`처럼 끊겨 보일 뿐. 입력은 **Shift + `₩`** (Enter 위 키).
이름은 파이프 / 비트 OR.

## 2. 조각내서 읽기

```
bream_smelt_indexes  =  (train_target == 'Bream')  |  (train_target == 'Smelt')
                         └──── 조각 ① ────┘        ↑     └──── 조각 ② ────┘
                                                 자리마다 OR
```

- `배열 == 'Bream'` → 비교를 **원소마다** 해서 True/False 배열이 나옴
- `|` → ①과 ②를 **같은 자리끼리** OR

## 3. 왜 `or`가 아니라 `|`인가

| | `or` (파이썬 단어) | `|` (기호) |
|---|---|---|
| 대상 | True/False **하나** | True/False **배열** |
| 배열에 쓰면 | 에러 (`truth value ... is ambiguous`) | 자리별 계산 |

배열끼리는 `|`(또는), `&`(그리고), `~`(부정)을 쓴다.

## 4. 괄호가 필요한 이유

`|`가 `==`보다 **먼저 계산**된다. 괄호를 빼면:

```
train_target == ('Bream' | train_target) == 'Smelt'   ← 엉뚱하게 묶여 에러
```

> [!tip] 정리
> 이 한 줄은 `[True, False, True, ...]` 체를 **조건으로 자동 생성**하는 코드다.
> 결과는 화면 출력이 아니라 **골라서 새 변수에 저장**하는 것.
