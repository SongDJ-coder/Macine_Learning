# 최소제곱법 수학적 유도 (책 범위 밖 심화)

> [[ch03|← 3장 원리 노트로 돌아가기]]

`LinearRegression.fit()`이 어떻게 계수를 "계산"해내는지, 시행착오 없이 공식 하나로
풀리는 원리.

## 1단계: 오차 제곱합을 수식으로

```
SSE(w, b) = Σᵢ (yᵢ - (w·xᵢ + b))²
```

## 2단계: "그릇 바닥" = 미분값이 0인 지점

`w`, `b`를 바꿔가며 SSE를 그리면 아래로 볼록한 그릇 모양(convex)이 됨 — 바닥에서는
어느 방향으로 움직여도 기울기(미분값)가 0. 각각 편미분해서 0으로 놓으면:

```
∂SSE/∂w = Σᵢ 2(yᵢ - w·xᵢ - b)·(-xᵢ) = 0
∂SSE/∂b = Σᵢ 2(yᵢ - w·xᵢ - b)·(-1) = 0
```
정리하면:
```
Σxᵢyᵢ - w·Σxᵢ² - b·Σxᵢ = 0
Σyᵢ - w·Σxᵢ - b·n = 0
```
미지수 `w`, `b` 2개짜리 연립방정식 — **정규방정식(normal equation)**. 바로 풀림.

## 3단계: 특성이 여러 개(행렬)일 때 — 일반화

```
SSE(w) = (y - Xw)ᵀ(y - Xw)
```
- `X`: `(샘플수, 특성수)` 행렬 (`train_poly`처럼)
- `w`: 각 특성의 계수를 모은 벡터
- `y`: 정답 벡터

### 숫자 예시로 뜯어보기 (3샘플, 2특성: 길이², 길이)

```
        [길이²  길이]
X   =   [  4     2 ]   w = [w1]   y = [15]
        [  9     3 ]       [w2]       [25]
        [ 16     4 ]                  [40]
```

**`Xw` = 예측값을 한 번에 계산** (행렬×벡터 = 각 행마다 특성×계수를 다 더함):
```
w1=1, w2=2라고 하면
Xw = [4×1+2×2]   [8 ]
     [9×1+3×2] = [15]
     [16×1+4×2]  [24]
```

**`y - Xw` = 잔차(오차)**:
```
y - Xw = [15-8]   [7 ]
         [25-15] = [10]
         [40-24]   [16]
```

**`(y-Xw)ᵀ(y-Xw)` = 오차 제곱합** (벡터ᵀ×같은벡터 = 각 원소 제곱해서 합산):
```
7² + 10² + 16² = 49+100+256 = 405
```
→ `Σᵢ(yᵢ-예측ᵢ)²`랑 완전히 같은 식을 행렬 곱셈 한 방으로 표기한 것뿐.

### 미분해서 공식 유도

```
∂SSE/∂w = -2Xᵀ(y - Xw) = 0
       →  Xᵀy - XᵀXw = 0
       →  XᵀXw = Xᵀy
       →  w = (XᵀX)⁻¹ Xᵀy
```

> [!tip] 핵심
> 1단계의 연립방정식(스칼라)과 3단계의 행렬 공식은 **같은 것을 스칼라로 푸느냐
> 행렬로 푸느냐의 차이**일 뿐. 특성이 몇 개든(2개든 55개든) 이 공식 하나로 끝남 —
> 그래서 `fit()`이 데이터가 많아도 순식간에 끝남 (시행착오 없이 공식 계산 한 번).

## 시각적 이해

- 산점도 위에 피팅 직선을 긋고, 각 점에서 직선까지 수직 거리(잔차)를 그려보면
  그 거리들의 제곱합이 SSE.
- `w`, `b`를 x축/y축으로 두고 SSE를 등고선으로 그리면 오목한 밥그릇 모양이 나오고,
  그 바닥(최솟값 지점)이 바로 `fit()`이 찾아주는 답.
- (채팅에서 실제 matplotlib으로 이 두 그래프를 그려서 확인함 — 왼쪽: 잔차 시각화,
  오른쪽: SSE(w,b) 등고선 + 최소점 표시)
