# np.mean(axis=0/1)은 어느 방향으로 계산되는가

> [[ch02|← 2장 원리 노트로 돌아가기]]

**Q: `axis`에 따라서 행으로 계산할지 열로 계산할지가 달라지는 거지?**

맞음. `axis`는 "어느 축을 없애면서(뭉개면서) 계산할지"를 정하는 것.

`train_input`이 `(샘플 수, 2)` 형태(행=샘플, 열=특성: 길이/무게)라고 할 때:

- **`axis=0`**: 0번째 축(행 방향)을 없애면서 계산 → 세로로 훑어서 **열마다** 값 하나씩 남음
  → 결과: `[길이 전체 평균, 무게 전체 평균]` (shape `(2,)`)
- **`axis=1`**: 1번째 축(열 방향)을 없애면서 계산 → 가로로 훑어서 **행마다** 값 하나씩 남음
  → 결과: 샘플 하나하나의 (길이+무게) 평균 (지금 상황에선 의미 없는 계산)

> [!tip] 기억하는 법
> `axis=숫자`는 "그 축을 없앤다(뭉갠다)"는 뜻. `axis=0`은 행 축을 없애니까 → 열별 결과.
> "axis=0이니까 행 방향 결과"라고 반대로 외우면 헷갈리기 쉬움.

표준화할 때는 각 **특성(길이/무게)별로** 평균/표준편차를 구해야 하므로 `axis=0`이 맞는 선택.
