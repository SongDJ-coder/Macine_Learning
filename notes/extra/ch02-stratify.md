# stratify 매개변수가 정확히 뭘 하는가

> [[ch02|← 2장 원리 노트로 돌아가기]]

**Q: stratify는 원본 데이터의 클래스 비율에 맞춰서 훈련/테스트를 나눠준다는 얘기지?**

정확함. `stratify=fish_target`은 "**전체 데이터의 클래스 비율을, 나눈 뒤에도 그대로
유지해라**"는 뜻.

`fish_target`은 도미(1) 35개, 빙어(0) 14개 → 비율 약 **71% : 29%**.

```
stratify 없이 나누면 (운 나쁘면):
  훈련: 도미 30개, 빙어 5개 (86% : 14%)  ← 비율 틀어짐
  테스트: 도미 5개, 빙어 9개 (36% : 64%)  ← 완전히 반대로 틀어짐

stratify=fish_target으로 나누면:
  훈련: 도미 ~26개, 빙어 ~10개 (71% : 29%)  ← 원본과 비율 유지
  테스트: 도미 ~9개, 빙어 ~4개 (71% : 29%)  ← 원본과 비율 유지
```

sklearn이 전체를 그냥 랜덤 섞는 게 아니라, **클래스(층)별로 따로 떼어내서 같은 비율로
분배**하기 때문에 "층화(stratified) 추출"이라고 부름 — 이름 그대로 `stratify`.

> [!tip] 정리
> `stratify`는 [[ch02|샘플링 편향]] 문제를 해결하는 가장 간단한 방법. 데이터가 적거나
> 클래스 비율이 불균형할 때 특히 중요함.
