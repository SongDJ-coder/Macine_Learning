# 시그모이드로 변환해도 확률의 성질이 보존되는가

> [[ch04|← 4장 원리 노트로 돌아가기]]

**Q: 시그모이드로 얻은 값이 곧 확률에 대응될 것 같은데, 변환해도 확률의 특성이 그대로 보존되나?
선형 변환처럼 1:1로 대응되면서 변환될 것 같은데.**

## 1. 1:1 대응은 맞음 — 단, 근거는 "선형"이 아니라 "단조증가"

시그모이드는 선형 변환이 아니다 (`σ(a+b) ≠ σ(a) + σ(b)`).
대신 **단조증가 함수**라서 z가 커지면 σ(z)도 반드시 커진다. 같은 값이 두 번 나오지 않으므로
서로 다른 z는 서로 다른 값에 대응한다 (전체 실수 → (0, 1)로의 1:1 대응).

## 2. 수학적으로 보장되는 것 (훈련과 무관)

**범위**: `e^(-z) > 0` → `1 + e^(-z) > 1` → `0 < σ(z) < 1`

**여사건의 합 = 1**: 이진 분류에서
```
P(클래스=1) = σ(z)
P(클래스=0) = 1 - σ(z)
합 = σ(z) + (1 - σ(z)) = 1     ← z가 무엇이든 항상 성립
```
"일어날 확률 + 일어나지 않을 확률 = 1"이라는 확률의 기본 성질이 보존된다.

## 3. 수학만으로는 보장되지 않는 것

σ(z)가 **믿을 만한 확률**인지(예: 모델이 70%라고 한 샘플들 중 실제로 약 70%가 그 클래스인지)는
시그모이드 공식이 아니라 **w, b를 어떻게 학습했는지**에 달려 있다.
로지스틱 회귀는 **로그 손실(cross-entropy)**을 최소화하도록 w, b를 학습하는데, 이 과정이 σ(z)를
실제 데이터의 비율에 맞춰준다. w, b를 아무렇게나 정하면 σ(z)는 여전히 (0,1) 안의 숫자이고
합도 1이지만, 실제 확률과는 맞지 않는 숫자가 된다.

> [!tip] 정리
> | 성질 | 보장하는 것 |
> |---|---|
> | 0~1 범위, 여사건 합 = 1 | 시그모이드 함수 자체 (항상 참) |
> | 실제로 믿을 만한 확률값인가 | 훈련 과정 (로그 손실 최소화) |

> [!info] 다중 분류에서는
> 클래스가 3개 이상이면 시그모이드를 클래스마다 따로 쓰면 **합이 1이 안 된다.**
> 그래서 다중 분류에서는 모든 클래스의 합이 1이 되도록 정규화하는 **소프트맥스(softmax)**를 쓴다.
