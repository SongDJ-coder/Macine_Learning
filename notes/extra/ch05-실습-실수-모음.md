## 2. 표준화로 학습하고 원래 값으로 평가 (0.758)

```python
dt.fit(train_scaled, train_target)
dt.score(train_input, train_target)    # ❌ 0.758
dt.score(train_scaled, train_target)   # ✅ 0.845
```

저장된 질문은 `sugar <= -0.239`(표준화 단위). 원래 당도는 항상 양수 → 모든 와인이 "아니오" 쪽으로 감.
**fit에 쓴 데이터와 같은 전처리로 평가·예측해야 한다** (04-2의 "같은 자로 재기"와 같은 원리).

## 3. plot_tree의 feature_names 순서

```python
plot_tree(dt, feature_names=['alcohol', 'pH', 'sugar'])   # ❌ 학습 열 순서와 다름 → 이름이 잘못 붙음 (에러 없음)
plot_tree(dt, feature_names=['alcohol', 'sugar', 'pH'])   # ✅
```

`x[1]` = 1번 열 = sugar. 이름 리스트는 단지 번호에 이름표를 붙일 뿐이라 순서가 틀려도 경고가 안 난다.
