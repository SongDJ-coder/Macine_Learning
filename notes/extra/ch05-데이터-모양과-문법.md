## 특성은 2차원, 정답은 1차원

```
data = wine[['alcohol', 'sugar', 'pH']]   shape (6497, 3)   ← 문제지: 샘플 1개당 값 여러 개
target = wine['class']                     shape (6497,)     ← 답안지: 샘플 1개당 답 1개
```

| 쓰는 법 | 결과 |
|---|---|
| `wine[['a', 'b']]` (리스트를 넘김) | DataFrame, 2차원 |
| `wine['class']` (문자열 하나) | Series, 1차원 |

**Q: 2차원이면 `[[alcohol 전부], [sugar 전부], [pH 전부]]` 모양인가?** → 아님. **샘플(와인)별로** 묶인다.

```
❌ (3, 6497)                  ✅ (6497, 3)
[[alcohol 6497개],            [[9.4, 1.9, 3.51],   ← 0번 와인
 [sugar   6497개],             [9.8, 2.6, 3.20],   ← 1번 와인
 [pH      6497개]]             ...]
```

sklearn 특성 데이터는 항상 **(샘플 수, 특성 수)**. 가로줄 하나 = 샘플 하나.

## 함수 vs 클래스

| | 함수 (`train_test_split`, `cross_validate`) | 클래스 (`StandardScaler`, `DecisionTreeClassifier`, `StratifiedKFold`) |
|---|---|---|
| 사용 | 바로 호출 → 결과 받고 끝 | 객체를 만들고 메서드 호출 |
| 기억할 것 | 없음 | 있음 (평균·표준편차, 질문 목록, 분할 설정 …) |
| 이름 관례 | 소문자_밑줄 | 대문자로 시작 |

`import`는 이름을 **가져오기만** 한다. 객체 생성이 아님.

```python
import sklearn
sklearn.set_config(display='text')       # ✅ 두 줄 (import 다음에 호출)
import sklearn._config(display='text')   # ❌ SyntaxError: import 문에서는 호출 불가
```

## 속성 vs 메서드

```
train_input.shape    → 속성: 객체가 들고 있는 값  → 괄호 없음
train_input.head()   → 메서드: 객체가 하는 동작   → 괄호 있음
```

`train_test_split`이 돌려준 `train_input`은 이미 DataFrame **객체**라서 `.shape`, `.head()`를 바로 쓸 수 있다.
메서드에 괄호를 빼면(`fish.head`) 실행되지 않고 함수 자체가 출력된다.
