# 📘 2장 데이터 다루기

## 02-1 훈련 세트와 테스트 세트

| | 입력 | 정답(타겟) | 예시 |
|---|---|---|---|
| **지도학습** | O | O | 1장 도미/빙어 분류 (`fish_data` + `fish_target`) |
| **비지도학습** | O | X | 군집(K-means), 주성분분석(PCA) — 6장 |
| **강화학습** | 행동+보상 | — | 책 범위 밖 |

### 왜 훈련/테스트 세트를 나누는가
같은 데이터로 학습하고 평가하면 정확도가 항상 부풀려짐 (이미 외운 문제로 시험 보는 것과 같음).
그래서 **훈련 세트**로 `fit()`, 한 번도 안 본 **테스트 세트**로 `score()` 해서 진짜 성능을 확인한다.

### 샘플링 편향(sampling bias)
```
fish_data 순서: [도미 35개, 빙어 14개]

앞 35개=훈련, 뒤 14개=테스트로 그냥 자르면
   → 훈련 세트: 도미만 있음
   → 테스트 세트: 빙어만 있음   ← 완전히 잘못된 분리
```
**해결**: `np.random.shuffle()`로 인덱스를 섞은 뒤 분리하거나, `sklearn.train_test_split()` 사용.

## 02-2 데이터 전처리

### 문제: 특성의 스케일이 다르면 거리 계산이 왜곡됨

길이(10~40대)와 무게(수백~천 단위)는 값의 범위가 완전히 다르다. k-NN은 유클리드 거리로
이웃을 찾는데, **값이 큰 특성(무게)이 거리 계산을 지배**해버린다. `kneighbors()`로 실제
뽑힌 이웃을 확인해서 산점도에 그려보면, 눈으로는 가까워 보이는 점이 실제로는 이웃으로
안 뽑히고 다른 클래스 점이 이웃으로 뽑히는 걸 확인할 수 있다.

### 해결: 표준화(standardization)

```
mean = 특성별 평균 (axis=0)
std  = 특성별 표준편차 (axis=0)

표준화된 값 = (원본값 - mean) / std
```
→ 모든 특성이 평균 0, 표준편차 1인 같은 스케일로 맞춰짐

### 🔑 핵심 원리 — 훈련 세트 기준을 테스트 세트에도 그대로 적용

> [!warning] 가장 중요한 포인트
> 표준화에 쓴 `mean`, `std`는 **반드시 훈련 세트에서 구한 값**이어야 한다. 테스트 세트나
> 새로운 샘플을 예측할 때도 **그 값을 그대로 재사용**해서 변환해야 함 — 테스트 세트
> 자신의 mean/std로 다시 계산하면 안 됨. 기준이 달라지면 모델이 잘못 판단하게 된다.

```
훈련:     train_scaled = (train_input - train_mean) / train_std
          kn.fit(train_scaled, train_target)

예측/평가: test_scaled = (test_input - train_mean) / train_std   ← train 기준 재사용!
          kn.score(test_scaled, test_target)
```

### 사이킷런 사용 규칙 두 가지

- `train_test_split(..., stratify=target)`: 원본 클래스 비율을 유지하며 분리
