# 혼자 공부하는 머신러닝+딥러닝 학습 저장소

박해선 저, 『혼자 공부하는 머신러닝+딥러닝』(한빛미디어)을 따라가며 정리하는 개인 학습 저장소입니다.
챕터별 폴더에 실습 코드와 핵심 개념 노트를 함께 저장합니다.

## 사용 방법

1. `requirements.txt`로 실습 환경을 구성합니다.
2. 각 챕터 폴더(`chXX_.../README.md`)에서 그 장의 핵심 개념을 정리합니다.
3. 같은 폴더의 `.py` 스크립트에서 책의 예제 코드를 직접 실습합니다.
4. 진도가 나갈 때마다 아래 진행 체크리스트를 갱신합니다.

## 진행 체크리스트

| 장 | 제목 | 폴더 | 상태 |
|---|---|---|---|
| 1 | 나의 첫 머신러닝 | [`ch01_my_first_ml`](./ch01_my_first_ml) | 진행 중 |
| 2 | 데이터 다루기 | [`ch02_handling_data`](./ch02_handling_data) | 예정 |
| 3 | 회귀 알고리즘과 모델 규제 | [`ch03_regression`](./ch03_regression) | 예정 |
| 4 | 다양한 분류 알고리즘 | [`ch04_classification`](./ch04_classification) | 예정 |
| 5 | 트리 알고리즘 | [`ch05_tree`](./ch05_tree) | 예정 |
| 6 | 비지도 학습 | [`ch06_unsupervised`](./ch06_unsupervised) | 예정 |
| 7 | 딥러닝을 시작합니다 | [`ch07_deep_learning_intro`](./ch07_deep_learning_intro) | 예정 |
| 8 | 이미지를 위한 인공 신경망 | [`ch08_cnn`](./ch08_cnn) | 예정 |
| 9 | 텍스트를 위한 인공 신경망 | [`ch09_rnn`](./ch09_rnn) | 예정 |

## 환경 설정

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
