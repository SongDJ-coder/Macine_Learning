# 1장 나의 첫 머신러닝

## 01-1 인공지능과 머신러닝, 딥러닝

- **인공지능(AI)**: 사람처럼 학습하고 추론할 수 있는 지능을 컴퓨터로 구현한 기술 전반.
- **머신러닝(ML)**: 규칙을 사람이 일일이 코딩하지 않고, 데이터에서 규칙(패턴)을 스스로 학습하는 알고리즘. 대표 라이브러리: scikit-learn.
- **딥러닝(DL)**: 머신러닝의 한 종류로, 인공 신경망(특히 층이 많은 신경망)을 사용하는 방법. 대표 라이브러리: TensorFlow, PyTorch.

관계: AI ⊃ 머신러닝 ⊃ 딥러닝

## 01-3 마켓과 머신러닝 — 도미와 빙어 분류

첫 번째 머신러닝 프로그램: 생선의 길이와 무게로 도미(bream)와 빙어(smelt)를 구분하는
**k-최근접 이웃(k-Nearest Neighbors, k-NN)** 분류기를 만듭니다.

핵심 개념:
- **특성(feature)**: 데이터를 표현하는 값 (여기서는 길이, 무게).
- **훈련(fit)**: 모델이 데이터에서 규칙을 학습하는 과정.
- **k-최근접 이웃 알고리즘**: 새로운 데이터가 들어오면, 가장 가까운 k개의 이웃 데이터를 찾아
  다수결로 클래스를 예측. 별도의 명시적 규칙이 없어 이해하기 쉽지만, 데이터가 많아지면 느려진다.

실습 코드: [`fish_classification.py`](./fish_classification.py)

```bash
python ch01_my_first_ml/fish_classification.py
```
